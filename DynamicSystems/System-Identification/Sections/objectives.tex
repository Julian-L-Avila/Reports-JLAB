\section{Objetivos}
\begin{itemize}
    \item Elaborar modelos de primer y segundo orden que representen el comportamiento de un horno eléctrico.
    \item Determinar las constantes de las funciones de transferencia correspondientes a los diferentes modelos.
    \item Analizar cuál de los modelos se ajusta mejor al comportamiento real de un horno eléctrico.
\end{itemize}
